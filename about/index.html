  • 掌握前端开发完整周期， CI/CD 实现，并能完全从零实现 Devops 流水线
  • 掌握业务项目中的工程化配置，并进行定制化处理
  • 能基于 Node.js 开发脚手架、打包构建优化工具及中间件服务
  • 在项目架构设计与性能优化方面有一定的经验

项目经历

电商购物

项目简介

为用户提供好商品、好价格、好服务的购物体验，打造用户优惠，商家实惠的数组生活体验。基于 mPaaS 服务，包含移动端（H5、小程序）。

技术栈

mPaaS、uniapp、Vue、Vuex、uni-simple-router、Webpack、JSBridge、SDK、JavaScript

核心成果

  • 主导用户埋点基础搭建，选用通用神策数据及 mPaaS 服务套件 MAS，通过统计和分析客户端流量、性能质量和用户行为等数据，用数据实现产品、运营、推广的决策；
  • uni-app 实现小程序及 H5 多端功能统一开发；
  • 优化项目中核心流程交互与性能，包括：搜索推荐、客服系统、公共组件、广告投放及 300ms 延
    迟；
  • 主导小程序性能优化，降低代码体积，减小资源加载、首屏渲染耗时；
  • 负责日常 to C 的 CMS 迭代研发和维护；

活动专区低代码平台

项目简介

基于特定节假日、促销活动投放商品场景，提供涵盖数据源与加工、页面组装、流程引擎、低代码编辑
器、AI 辅助数据建模、AI 托管式应用构建等功能。

技术栈

Vue、Vue Router、Vue-CLI、pinia、Vite、monaco-editor、TypeScript、husky

核心成果

  • 负责平台技术选型、基础架构及方案设计，包括：工程化相关方案设计与落地、核心模块方案设计与实现；
  • 制定 eslint、stylelint、commitlint、markdownlint、husky 等工具规范，产出高质量代码；
  • 主导页面组装模块设计，选用通用 blocksuite 方案，丰富页面元素，高度可定制；
  • 服务编排及流程引擎等内容实现；

电商运营平台

项目简介

为商家提供一站式电子商务解决方案的服务体系，它涵盖了商品交易、物流配送、售后服务等环节，旨
在帮助商家提高销售业绩、优化客户体验并增强品牌价值。

技术栈

React 、React Router、Redux、Ant Design、Webpack、TypeScript

核心成果

  • 负责日常 to B 的 CMS 迭代研发和维护；
  • 主导设计并研发动态表单部分，减少代码冗余，提高开发效率；
  • 主导性能优化，实施代码分割和懒加载策略，减少应用的初始加载时间；
