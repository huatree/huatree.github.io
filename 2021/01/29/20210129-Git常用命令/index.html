三十五、最容易混淆的几个命令

add

把工作区修改放入暂存区。

commit

把暂存区内容创建成新的 Commit。

push

把本地 Commit 推送到远程。

fetch

获取远程最新信息，但不直接合并到当前分支。

pull

获取远程更新，并进行 merge 或 rebase。

merge

把另一个分支的历史合并进当前分支。

rebase

把当前分支的 Commit 重新应用到新的基线之上。

cherry-pick

把指定 Commit 的修改复制到当前分支。

reset

调整当前分支指针，常用于修改本地历史。

revert

创建新的 Commit，抵消之前 Commit 的修改。

restore

恢复工作区文件，或者通过：

取消暂存。
